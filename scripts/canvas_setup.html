先准备好这三件事

① 在浏览器登录学校 Canvas，确认课程可见。交大用户如需校园网络，请先连接。

② 使用 Python 3.11 或更高版本，准备 requests 和系统 curl。分享包内的 run_canvas.py 会检查环境，不会自动安装依赖。

③ 决定资料保存在哪里：复用已有课程目录，或为新学期选一个尚不存在的新文件夹。

不需要 AI Agent。完成向导后，每次运行启动脚本即可打开网页。
熟悉命令行？最短启动方式
python run_canvas.py
# 缺少依赖时，先为自己的 Python 环境安装 requirements.txt
# 可通过 --config 指定独立配置文件

连接自己的 Canvas 账号

其他学校可填写自己的 Canvas HTTPS 根地址。Token 只保存在本机配置中，不包含在分享包内。
怎样获取 Token？

在 Canvas 打开「账户 → 设置」，向下滚动至「允许融入使用的外部软件」，点击表格下方「＋创建新访问许可证」。填写用途并完成创建后，将显示的 Token 复制到上方。不同学校可能禁用此功能，届时需联系学校支持。不要发送完整 Token 截图或分享个人配置文件。

选择学期、位置与整理规则

路径属于运行 Python 的这台电脑。目录名称可包含空格。可复用原目录；初始化时须选择新目录。

课程范围

账号测试成功后可勾选本学期课程；不限制课程时，每次扫描查询当前可见课程。

连接测试读取当前课程；历史课程可取消课程限制后扫描，或在高级课程映射中填写历史课程 ID。
自定义目录和下载选项
测试连接后自动填充。可改为已有课程目录名；每个值只能是一个目录名。新学期初始化按此清单创建子文件夹。

预览后保存

请核对位置和目录名称。保存账号与整理规则后，网页将清空旧扫描结果，等待重新扫描。
